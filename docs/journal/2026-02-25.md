**Implication**: DVOL is a pure random walk without deterministic components. This explains:
- **High R² (~0.90)**: y[t+1] ≈ y[t] + ε → predicting y[t] gives excellent level forecasts

This is **consistent with efficient market hypothesis** - implied volatility should be unpredictable as it already incorporates all available information.

## 6. Why High R² but Low Directional Accuracy?

### Accepted Explanation: Signal-to-Noise in Random Walk

1. **Level prediction works**: DVOL[t+1] ≈ DVOL[t] + small_noise
   - Small variance in noise → high R² when predicting levels

2. **Direction prediction fails**: sign(small_noise) ≈ random
   - 50% accuracy is expected for unpredictable noise

3. **This is NOT spurious regression**:
   - Rolling normalization achieves stationarity
   - High R² reflects genuine predictive power for LEVELS
   - Low DA reflects inherent unpredictability of DIRECTION in a random walk

## 12. Lee-Mykland Formula Verification (February 25, 2026)

### Investigation Trigger
Question: "How are the jumps being detected? Use web search to find the standard formula and verify consistency."

### Finding: Current Implementation ≠ Standard Lee-Mykland (2008)

**The v1.3 dataset uses a simplified data-driven jump detection method that does NOT follow the standard Lee-Mykland (2008) specification.**

### Standard Lee-Mykland Formula (Academic Literature)

```text
1. Returns: r_t = log(S_t) - log(S_{t-1})  [log returns]

2. Bipower Variation: BPV_t = |r_{t-1}| × |r_t|
   Estimated volatility: σ_t = sqrt(rolling_mean(BPV, k))

3. L-statistic: L_t = r_t / σ_t

4. Normalized test statistic:
   n = sample_size
   c = sqrt(2/π)
   S_n = c × sqrt(2 × log(n))
   C_n = S_n/c - log(π × log(n))/(2 × c × S_n)

5. Threshold (Gumbel EV theory):
   β* = -log(-log(1 - α))  ≈ 9.21 for α = 0.0001

6. Jump detection: J_t = 1 if (|L_t| - C_n) × S_n > β*
```

### Current Implementation (fix_methodology_issues.py lines 64-94)

```python
# 1. Percentage change (not log returns)
returns = df['dvol'].pct_change()

# 2. Simplified bipower variance
bipower_var = (π/2) × (rolling_mean(|returns|, 24))^2

# 3. Different L-statistic (squared returns)
L = (returns^2) / bipower_var
S_n = (1/c) × sqrt(24) × (L - 1)

# 4. Data-driven threshold (not Gumbel-based)
threshold = min(quantile(S_n, 0.999), mean(S_n) + 3.5×std(S_n))
jumps = S_n > threshold
```

### Comparison Table

| Aspect | Standard Lee-Mykland | Current Implementation |
| :--- | :--- | :--- |
| Return type | `diff(log(S))` | `pct_change()` |
| Bipower variation | `\|r_{t-1}\| × \|r_t\|` | `(π/2) × mean(\|r\|)^2` |
| L-statistic | `r / σ` | `r^2 / bipower_var` |
| Sample size | `n` (total obs) | `window=24` |
| Threshold | Gumbel EV: ~9.21 | Data-driven: ~93.52 |
| Jumps detected | Varies by data | 503 (1.23%) |

## 13. Dataset v1.4: Standard Lee-Mykland Jump Detection (February 25, 2026)

### Context

Following verification that v1.3 used a simplified data-driven jump detection method instead of the standard Lee-Mykland (2008) formula, v1.4 was created with the academically correct implementation.

### Implementation

Created `scripts/analysis/standard_lee_mykland.py` implementing the standard Lee-Mykland test:

```python
# 1. Log returns: r_t = log(S_t) - log(S_{t-1})
log_returns = diff(log(prices))

# 2. Bipower Variation: BPV_t = |r_{t-1}| × |r_t|
abs_returns = abs(log_returns)
bpv = abs_returns[:-1] * abs_returns[1:]

# 3. Rolling volatility estimation
sigma_t = sqrt(rolling_mean(bpv, k))

# 4. L-statistic: L_t = r_t / sigma_t
L_t = log_returns / sigma_t

# 5. Normalized test statistic (Extreme Value Theory)
c = sqrt(2/pi)
S_n = c * sqrt(2 * log(n))
C_n = S_n/c - log(pi * log(n)) / (2 * c * S_n)
T_t = (|L_t| - C_n) * S_n

# 6. Gumbel threshold
beta_star = -log(-log(1 - alpha))  # = 9.21 for alpha = 0.0001

# 7. Jump detection
jumps = (T_t > beta_star)
```
