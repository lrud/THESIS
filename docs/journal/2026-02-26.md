## Methodology Correction

### Directional Accuracy Formula (CORRECTED)

**Issue Found (2026-02-26):** Previous directional accuracy calculations used an incorrect formula. The notebook has been updated to use the **industry standard Pesaran-Timmermann (1992)** formula:

$$MDA = \frac{1}{N} \sum_{t=1}^{N} \mathbf{1}\left[\text{sgn}(A_t - A_{t-1}) = \text{sgn}(F_t - A_{t-1})\right]$$

Where:
- $A_t$ = actual value at time $t$
- $F_t$ = forecast value for time $t$
- The key difference: predicted direction uses $A_{t-1}$ (last actual), not $F_{t-1}$ (last forecast)

**Impact:** Corrected directional accuracy values are **~4-5 percentage points lower** than previously reported. All values below use the corrected formula.

**Reference:** Pesaran, M. & Timmermann, A. (1992). "A simple nonparametric test of predictive performance". *Journal of Business & Economic Statistics*, 10(4), 461-465.

## Critical Insights

### 1. High R² is Misleading
- R² values of 99%+ are due to **high autocorrelation** in DVOL
- DVOL correlation between t and t+1: **0.999235** (verified on v1.6_final dataset)
- Predicting **levels** is trivial; predicting **direction** is difficult

### 2. Directional Accuracy is Barely Better than Random
- Best model (HAR_RV at 168h): **50.8%**
- Random guessing: 50%
- Simple HAR_RV (3 features) **consistently outperforms** complex models for directional accuracy

### 3. Model Complexity Doesn't Help Directional Prediction
- Complex models (XGBoost, RF) achieve R² > 99% but Dir% ~49%
- Simple HAR_RV achieves R² ~95% but Dir% ~51%
- **Trade-off:** Higher R² does not imply better directional signals

### 4. 72-Hour Window is Optimal for Level Prediction
- Best average R²: 0.9902 (72h)
- Best single model R²: 0.9940 (XGB_NoLag_Jumps at 72h)
- Longer windows (30d) show degraded performance

## Recommendations

### For Level Prediction
- **Use 72-hour (3-day) normalization window** - empirically proven best
- **Model:** XGB_NoLag_Jumps (8 features)
- **Expected performance:** R² ≈ 0.994, RMSE ≈ 0.53
- **Features:** market metrics + jump features

### For Directional Signals
- **Any window works** - HAR_RV Dir% is stable across all windows (50.3-50.8%)
- **Model:** HAR_RV (3 features: dvol_lag_1d, dvol_lag_7d, dvol_lag_30d)
- **Expected performance:** Dir% ≈ 50-51%
- **Advantage:** Simple, interpretable, robust

### Key Takeaway

**High R² ≠ Better Directional Signals.** The finding that HAR_RV achieves the best directional accuracy despite the lowest R² is **counterintuitive but important**: simpler models may provide more reliable trading signals even when they appear "worse" by traditional metrics.
